## راهنمای افزودن اسکرین‌شات جدید

1. تصویر را با نام کوتاه، انگلیسی و توصیفی (kebab-case) در همین پوشه ذخیره کنید.
2. در فایل Markdown مربوطه، خط `📸 محل پیشنهادی تصویر:` را با ارجاع مستقیم به تصویر جایگزین کنید:
   ```markdown
   ![نام تصویر](../assets/screenshots/NAME.png)
   ```
3. ترجیحاً عرض تصاویر پنل بین ۶۰۰ تا ۹۰۰ پیکسل باشد تا در GitHub خوانا نمایش داده شوند.
