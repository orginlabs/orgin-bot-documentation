# 🖼️ پوشهٔ تصاویر رسمی (Images)

این پوشه برای نگهداری لوگو، بنر و آیکون‌های رسمی برند **Orgin Bot** استفاده می‌شود.

## فایل‌های موجود

| فایل | کاربرد |
|---|---|
| `orgin-banner.jpg` | بنر اصلی نمایش‌داده‌شده در بالای `README.md` |
| `orgin-icon.jpg` | آیکون/لوگوی اصلی ربات (فرمت گرد سبزرنگ) |
| `orgin-game-logo.jpg` | لوگوی ربات همکار Orgin Game، استفاده‌شده در سند [پریمیوم](../../docs/12-premium.md) |

## راهنمای افزودن تصاویر جدید

هنگام افزودن لوگوی جدید یا نسخهٔ به‌روزشدهٔ برند:

1. تصویر را با نام واضح و انگلیسی (kebab-case) در همین پوشه قرار دهید. مثال: `orgin-icon-dark.png`
2. در فایل Markdown مربوطه با تگ `<img src="./assets/images/NAME" ...>` یا لینک استاندارد `![alt](./assets/images/NAME)` ارجاع دهید.
3. ترجیحاً فرمت PNG با پس‌زمینهٔ شفاف برای لوگو و آیکون استفاده شود.
