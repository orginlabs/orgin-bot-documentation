## افزودن یا جایگزینی تصویر

نام فایل را توصیفی و با حروف لاتین انتخاب کنید؛ تصویر تازه را به همین پوشه اضافه کنید و پیوند نسبی آن را در سند مربوط قرار دهید. برای درج در Markdown از این الگو استفاده کنید:

```markdown
![توضیح کوتاه تصویر](./example.png)
```

برای بنرها طرح را روشن، خلوت و خوانا نگه دارید؛ متن جایگزین را فراموش نکنید و اطلاعات شخصی یا تصویر کاربران را بدون اجازه منتشر نکنید.
