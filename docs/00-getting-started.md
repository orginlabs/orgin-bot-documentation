# شروع سریع

## شروع سریع

۱. از لینک [ربات ارجین](https://t.me/orginv1bot) وارد پیوی شو و `/start` رو بفرست.

۲. دکمه **«افزودن به گروه»** رو بزن و گروهت رو انتخاب کن.

۳. ارجین رو توی گروه ادمین کن و دسترسی‌هاش رو بده. بدون دسترسی کافی، کارهایی مثل حذف پیام، سکوت یا بن‌کردن اعضا انجام نمی‌شن.

۴. برگرد به پیوی ربات، وارد **«گروه‌های من»** شو و گروهت رو انتخاب کن تا پنل مدیریتش باز بشه.

۵. برای دیدن دستورها `/help` رو بفرست، یا توی گروه کلمه **راهنما** رو بنویس.

> **نکته:** برای بیشتر دستورهای مدیریتی کافیه روی پیام اون عضو ریپلای کنی و دستور رو بفرستی. بعضی دستورها رو با آیدی عددی یا یوزرنیم عضو هم می‌شه اجرا کرد.
