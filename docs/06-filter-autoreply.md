## الف) فیلتر کلمات و عبارات نامناسب

کلمات ناخواسته (فحش، تبلیغات رقیب و…) به‌محض تایپ شدن در گروه، به‌طور خودکار حذف می‌شوند.

| دستور | عملکرد |
|---|---|
| `فیلتر [کلمه یا عبارت]` | افزودن یک واژه به لیست سیاه. مثال: `فیلتر تبلیغ چنل` |
| `فیلتر کلمه1, کلمه2, کلمه3` | افزودن دسته‌جمعیِ چند کلمه با استفاده از ویرگول |
| `حذف فیلتر [کلمه]` | آزادسازی و حذف یک واژه از لیست سیاه |
| `لیست فیلتر` (یا `کلمات ممنوعه`) | مشاهدهٔ جدول کامل کلمات فیلترشدهٔ چت |
| `پاکسازی لیست فیلتر` | حذف کامل تمام لیست فیلتر |

**مثال:**
```text
فیلتر صیغه
```

## ب) پاسخ‌های هوشمند خودکار (Custom Answers)

| دستور | عملکرد |
|---|---|
| `پاسخ [کلمه] به [جواب]` | تعریف پاسخ خودکار برای یک کلمهٔ کلیدی |
| `حذف پاسخ [کلمه]` | لغو پاسخ ثبت‌شده برای آن واژه |
| `لیست پاسخ ها` (یا `لیست پاسخ`) | نمایش کلیهٔ واژه‌های کلیدی و پاسخ‌های معادل آن‌ها |
| `پاکسازی پاسخ ها` (یا `پاکسازی پاسخ‌ها`) | حذف یکجای کلیهٔ پاسخ‌های خودکار تعریف‌شده |

**مثال:**
```text
پاسخ تعرفه به تعرفه خدمات ما در سایت ثبت شده است.
```
```text
پاسخ سلام به سلام عزیز دل خیلی خوش اومدی 🌹
```
