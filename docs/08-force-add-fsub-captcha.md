## الف) سیستم اد اجباری (Force Add)

روشی برای رشد اعضای گروه: هر کاربر باید تعداد مشخصی از مخاطبینش را اد کند تا اجازهٔ چت داشته باشد.

**دسترسی گرافیکی:** `پنل` ← «🚀 تنظیمات پیشرفته» ← «🔮 اد اجباری» (انتخاب تعداد: ۱ / ۲ / ۳ / ۵ / ۱۰ یا خاموش)

| دستور | عملکرد |
|---|---|
| `اد اجباری روشن` | فعال‌سازی شرط اد |
| `اد اجباری خاموش` | غیرفعال‌سازی سیستم |
| `اد اجباری [تعداد]` | تعیین تعداد لازم، از ۱ تا ۱۰ نفر. مثال: `اد اجباری 3` |
| `وضعیت اد من` (یا `اد کردن`) | نمایش آمار اد شما و بازشدن دکمهٔ «➕ اد کردن» برای دسترسی به مخاطبین |
| `پاکسازی ادها` | ریست کامل آمار اد گروه |

## ب) سیستم عضویت اجباری کانال (Force Subscription / F-Sub)

الزام عضویت اعضا در یک کانال مشخص؛ در غیر این صورت پیام‌هایشان حذف می‌شود.

**دسترسی گرافیکی:** `پنل` ← «🚀 تنظیمات پیشرفته» ← «📮 عضویت اجباری» (مشاهدهٔ کانال ثبت‌شده و فعال/غیرفعال‌سازی)

| دستور | معادل | عملکرد |
|---|---|---|
| `تنظیم کانال @ChannelID` | مثال: `تنظیم کانال @orginsupport` | ثبت آیدی کانال حامی |
| `عضویت اجباری روشن` | `قفل کانال` | فعال‌سازی الزام عضویت |
| `عضویت اجباری خاموش` | `بازکردن کانال` | غیرفعال‌سازی الزام عضویت |
| `حذف کانال` | — | پاکسازی کانال هدف از تنظیمات ربات |

> ⚠️ **نکتهٔ مهم:** ربات باید در کانال هدف مقام **ادمین** داشته باشد تا بتواند عضویت کاربران را بررسی کند.

---

## ج) کاپچای اعضای جدید (Join Captcha)

**دسترسی گرافیکی:** `پنل` ← «🚀 تنظیمات پیشرفته» ← «🔎 تایید هویت»

| دستور | عملکرد |
|---|---|
| `کاپچا روشن` | فعال‌سازی کاپچای ورودی |
| `کاپچا خاموش` | غیرفعال‌سازی کاپچای ورودی |

**کارکرد:** اعضای تازه‌وارد باید دکمهٔ **«من ربات نیستم 🤖»** را لمس کنند، در غیر این صورت پیام‌هایشان به‌طور خودکار حذف می‌شود.
