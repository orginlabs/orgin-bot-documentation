## الف) نقشهٔ پی‌وی ربات (Private Chat / PM Structure)

با ورود به پی‌وی ربات و ارسال دستور `/start`، دو رابط کاربری در اختیار کاربر قرار می‌گیرد:

### ۱. کیبورد لاین پایینی (Reply Keyboard)

این کیبورد همواره در پایین صفحهٔ چت در دسترس است:

| ردیف | دکمه سمت راست | دکمه سمت چپ |
|:---:|---|---|
| ۱ | 👥 گروه‌های من | 💎 خرید پریمیوم |
| ۲ | 🛡️ پروفایل من | ➕ افزودن به گروه |
| ۳ | 📚 راهنما | 💬 پشتیبانی |
| ۴ | 🎮 بازی‌ها | — |

> 👑 برای اکانت سازندهٔ ربات، دکمهٔ **«پنل سازنده»** نیز در ردیف نخست اضافه می‌شود.

### ۲. کیبورد شیشه‌ای پیام استارت (Inline Keyboard)

| دکمه سمت راست | دکمه سمت چپ |
|---|---|
| 💬 پشتیبانی | 🎮 بازی‌ها |
| 👥 گروه‌های من | ➕ افزودن به گروه |
| 💎 خرید پریمیوم | 🛡️ پروفایل من |
| 🌐 تنظیم زبان | 📚 راهنما |

> 👑 برای سازنده: دکمهٔ **«پنل سازنده»** در زیر این منو نمایش داده می‌شود.

### ۳. منوی «👥 گروه‌های من» — مدیریت از راه دور در پی‌وی

با کلیک روی **«👥 گروه‌های من»**:

1. فهرست کلیهٔ گروه‌های تحت مالکیت کاربر نمایش داده می‌شود.
2. با انتخاب هر گروه، پنل مدیریت اختصاصی همان گروه در پی‌وی باز می‌شود که شامل موارد زیر است:

| بخش | توضیح |
|---|---|
| ⚙️ تنظیمات پیشرفته گروه | دسترسی مستقیم به پنل ۱۷ بخشی از طریق پی‌وی |
| 🔄 به‌روزرسانی وضعیت قفل‌ها | مشاهده و تغییر لحظه‌ای قفل‌ها بدون نیاز به حضور در گروه |
| 💳 وضعیت لایسنس و تمدید | بررسی اعتبار اشتراک پریمیوم گروه |
| 📊 آمار لحظه‌ای چت و اعضا | گزارش زندهٔ فعالیت گروه |

### ۴. منوی راهنمای جامع در پی‌وی (📚 راهنما)

با کلیک روی «📚 راهنما» در پی‌وی یا گروه، فهرست ۱۱ سرفصل آموزشی زیر باز می‌شود:

<table>
<tr>
<td>

- 🔒 قفل‌ها و محدودیت‌ها
- ⚙️ تنظیمات مدیریتی
- 👤 دستورات کاربران
- 🧹 ابزار پاکسازی
- 💬 خوش‌آمد و خروج
- 📊 آمار فعالیت‌ها

</td>
<td>

- 🛡️ ضد تبچی
- ⚠️ اخطار و مجازات
- 👑 نقش‌ها و مدیران
- ⛔️ فیلتر کلمات
- 🔮 سیستم اد اجباری
- 📮 عضویت اجباری
- 🎮 بازی و سرگرمی
- 💎 لایسنس و امکانات

</td>
</tr>
</table>

## ب) نقشهٔ پنل شیشه‌ای گروه (In-Group Interactive Panel)

### منوی اصلی پنل گروه

| ردیف | دکمه سمت راست | دکمه سمت چپ |
|:---:|---|---|
| ۱ | 🔒 قفل‌ها | 📑 لیست‌ها |
| ۲ | 🚀 تنظیمات پیشرفته | 📚 راهنمای جامع |
| ۳ | ❌ بستن پنل | — |

### ۱. زیرمنوی 🔒 قفل‌ها (Locks Panel)

شامل **دو صفحهٔ** منظم و دسته‌بندی‌شده از کلیدهای روشن/خاموش است.

**📄 صفحهٔ اول (۱۱ ردیف کلید):**

| دکمه راست | دکمه چپ |
|---|---|
| هایپرلینک | لینک |
| هشتگ | یوزرنیم (@) |
| زبان فارسی | زبان انگلیسی |
| سرویس‌های تلگرام (پیام ورود/خروج) | پیام‌های متنی |
| فحش و توهین | ایموجی |
| دکمهٔ شیشه‌ای (اینلاین) | فوروارد پیام |
| هویت مخفی (ارسال با کانال) | بازی و گیم تلگرام |
| ورود ربات | اد کردن ربات |
| ربات مهمان | — |
| ویرایش رسانه | ویرایش متن پیام |
| ⏩ صفحه بعد | 🔙 بازگشت |

**📄 صفحهٔ دوم (۶ ردیف کلید):**

| دکمه راست | دکمه چپ |
|---|---|
| عکس | ویدیو |
| گیف | استیکر |
| ویس | آهنگ و صوت |
| فایل و سند | اشتراک مخاطب |
| موقعیت مکانی | نظرسنجی |
| پیش‌نمایش وب (WebPage) | دستورات عمومی اعضا |
| ⏪ صفحه قبل | 🔙 بازگشت |

📄 جزئیات کامل هر قفل → [۰۲ - قفل‌ها و محدودیت‌ها](./02-locks.md)
