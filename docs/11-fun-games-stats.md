## 🎲 سرگرمی و بازی‌های تعاملی

| دستور | معادل | عملکرد |
|---|---|---|
| `چالش` | `جرات حقیقت` | ارسال کارت گرافیکی شیشه‌ای جرأت یا حقیقت با ۴ دکمهٔ اینلاین: «حقیقت 🗣️»، «جرأت 🔥»، «تصادفی 🎲»، «مثبت ۱۸ 🔞» |
| `فال` | `فال حافظ` | غزل حافظ همراه با تعبیر و تفسیر دل‌نشین |
| `دانستنی` | `فکت` | حقایق علمی شگفت‌انگیز جهان |
| `جوک` | `لطیفه` | طنز و سرگرمی روز |
| `تاس` | `/dice` | انداختن تاس تصادفی |
| `سکه` | — | شیر یا خط تصادفی |
| `بازی` | `گیم` | هدایت به ربات بازی همکار [@orgingamerobot](https://t.me/orgingamerobot) |

## 📊 آمار فعالیت (Stats)

**دسترسی گرافیکی:** `پنل` ← «🚀 تنظیمات پیشرفته» ← «📊 گزارش و آمار»

| دستور | معادل / دستور اسلش | عملکرد |
|---|---|---|
| `وضعیت` | `آمار` \| `/status` | کارت گزارش وضعیت قفل‌ها و چت |
| `آمار امروز` | `پیام های امروز` | حجم پیام‌های ۲۴ ساعت اخیر گروه |
| `فعال‌ترین اعضا` | `تاپ چت` | جدول ۱۰ چت‌کنندهٔ برتر گروه |
