# مدیریت اعضا

### مدیریت اعضا

| کار | توضیح |
|:---|:---|
| بن و رفع بن | بن‌کردن عضو یا برداشتن بن |
| اخراج | بیرون‌انداختن عضو از گروه |
| سکوت | سکوت‌کردن عضو و برداشتن سکوت |
| اخطار | ثبت، حذف و مشاهده اخطارها |
| سقف اخطار | تعیین سقف و انتخاب اقدام بعد از رسیدن بهش |
| پین | پین‌کردن پیام و برداشتن پین |
| حذف پیام | حذف یک پیام یا پاک‌سازی چندتا پیام با هم |
| اطلاعات | دیدن اطلاعات و نقش اعضا |
| مدیرها | دیدن فهرست مدیرها و همگام‌سازی‌اش |

برای دستورهای بن، اخراج، سکوت، اخطار، پین و حذف پیام به [مرجع کامل دستورها](./14-commands-reference.md) هم مراجعه کن.
