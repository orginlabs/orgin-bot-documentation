# امنیت و مقابله با اسپم

### امنیت و مقابله با اسپم

ارجین چندتا ابزار داره که جلوی شلوغی و پیام‌های مزاحم رو بگیره:

| قابلیت | کارش |
|:---|:---|
| ضداسپم | جلوگیری از پیام‌های تکراری و مزاحم |
| ضدفلود | کنترل پیام‌های پشت‌سرهم |
| ضدتبچی | مقابله با حساب‌های تبلیغاتی شناسایی‌شده |
| ضدربات | کنترل ورود ربات‌ها به گروه |
| کپچا | بررسی اعضای تازه‌وارد قبل از شروع فعالیت |
| حالت شب | اجرای محدودیت‌ها در ساعت‌هایی که خودت تعیین می‌کنی |
| تأیید عضویت | کنترل ورود اعضا طبق تنظیمات گروه |
| ضدحمله | واکنش خودکار وقتی تعداد زیادی عضو تو مدت کم وارد گروه می‌شن |
| گزارش تخلف | خبرکردن مدیرها درباره یه پیام مشکل‌دار، همراه گزینه‌های رسیدگی |
| کانال گزارش مدیریتی | ثبت رویدادهای پشتیبانی‌شده برای پیگیری مدیرها |
| تشخیص اسپم با هوش مصنوعی | قابلیت **Pro**؛ بررسی پیام‌های مشکوک، در صورت فعال‌بودن |

بیشتر این گزینه‌ها رو از پنل گروه می‌تونی روشن و خاموش کنی. تنظیمات دقیق‌تر مثل تعداد پیام، بازه زمانی و مهلت کپچا هم از همون پنل انجام می‌شه.

### قفل‌های محتوا

می‌تونی مشخص کنی چه نوع پیام‌هایی توی گروه مجازن:

| دسته | قفل‌ها |
|:---|:---|
| متن و لینک | لینک، هایپرلینک، نام کاربری، هشتگ، متن، ویرایش پیام، فوروارد، اسپویلر |
| رسانه | عکس، ویدئو، GIF، استیکر، ویس، موسیقی، فایل |
| محتوای دیگه | مخاطب، موقعیت مکانی، نظرسنجی، بازی، دکمه‌های پیام، پیام با هویت کانال |
| زبان و متن | فحاشی، ایموجی، متن فارسی، انگلیسی یا عربی |

برای دیدن وضعیت قفل‌ها بفرست: `وضعیت قفل ها`

مثلاً قفل لینک رو این‌طوری کنترل کن:

| دستور | نتیجه |
|:---|:---|
| `قفل لینک` | لینک‌ها بسته می‌شن |
| `بازکردن لینک` | لینک‌ها آزاد می‌شن |
