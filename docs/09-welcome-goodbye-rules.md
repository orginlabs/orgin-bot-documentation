# خوشامد، خداحافظی و قوانین

### خوشامد، خداحافظی و قوانین

- پیام خوشامد برای اعضای تازه‌وارد
- پیام خداحافظی موقع خروج اعضا
- متن‌های پیش‌فرض چندزبانه
- متن خداحافظی اختصاصی برای گروه‌های واجد شرایط **Premium**
- ثبت و نمایش قوانین گروه
- فیلتر کلمات مشخص
- پاسخ خودکار برای عبارت‌های دلخواه
- تنظیم عنوان و توضیحات گروه (اگه دسترسی لازم رو داشته باشه)

اینا رو می‌تونی از بخش **«پیام‌ها»** توی پنل گروه تنظیم کنی یا با دستور:

| دستور | کاربرد |
|:---|:---|
| `تنظیم خوشامد` | متن خوشامد |
| `تنظیم خروج` | متن خداحافظی |
| `تنظیم قوانین` | قوانین گروه |
| `فیلتر کلمه1, کلمه2` | فیلتر کلمات |
| `پاسخ سلام به درود!` | پاسخ خودکار |

توی متن خوشامد و خداحافظی می‌تونی از متغیرهایی مثل نام عضو، نام گروه، تعداد اعضا، ساعت و تاریخ استفاده کنی.
