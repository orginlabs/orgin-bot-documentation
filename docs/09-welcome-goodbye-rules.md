## 👋 پیام خوش‌آمد

| دستور | عملکرد |
|---|---|
| `تنظیم خوشامد [متن]` | تعیین متن خوش‌آمدگویی دلخواه |
| `خوشامد روشن` | فعال‌سازی ارسال پیام خوش‌آمد |
| `خوشامد خاموش` | غیرفعال‌سازی پیام خوش‌آمد |
| `نمایش خوشامد` | نمایش متن فعلی خوش‌آمدگویی |

---

## 🚪 پیام خروج (خداحافظی)

| دستور | معادل | عملکرد |
|---|---|---|
| `تنظیم خداحافظی [متن]` | `تنظیم خروج [متن]` | تعیین متن خداحافظی دلخواه |
| `خداحافظی روشن` | `خداحافظی خاموش` | فعال/غیرفعال‌سازی پیام خروج |

## 🧩 متغیرهای هوشمند داینامیک

این متغیرها قابل استفاده در متن پیام خوش‌آمد، خداحافظی و سایر متن‌های سفارشی هستند:

| متغیر | خروجی |
|---|---|
| `{نام}` | نام کوچک کاربر |
| `{نام_خانوادگی}` | نام خانوادگی کاربر |
| `{نام_کامل}` | نام و نام خانوادگی کامل |
| `{منشن}` | لینک مستقیم و منشن پروفایل کاربر |
| `{آیدی}` | شناسهٔ عددی تلگرام کاربر |
| `{نام_گروه}` | عنوان گروه |
| `{تعداد_اعضا}` | آمار زندهٔ تعداد اعضا |
| `{تاریخ}` | تاریخ هجری شمسی امروز |
| `{ساعت}` | ساعت رسمی کشور به وقت تهران |

**مثال کاربرد:**

```text
تنظیم خوشامد سلام {منشن} عزیز به گروه {نام_گروه} خوش اومدی 🌹
```
