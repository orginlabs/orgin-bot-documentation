# رایگان و Premium

## نسخه رایگان و Premium

### نسخه رایگان

برای شروع مدیریت گروه، نسخه رایگان کلی امکانات کاربردی داره: بیشتر دستورهای مدیریت اعضا، قفل‌ها، خوشامد، قوانین، آمار و ابزارهای معمول. فهرست دقیقش رو توی پنل و راهنمای داخل ربات می‌بینی.

### Premium چی اضافه می‌کنه؟

بسته به قابلیت و وضعیت گروه، با Premium این امکانات هم باز می‌شن:

| امکان | توضیح |
|:---|:---|
| خداحافظی اختصاصی | متن خداحافظی مخصوص گروه خودت |
| سیستم تیکت | ثبت و پیگیری درخواست‌ها |
| پشتیبان‌گیری | دریافت نسخه پشتیبان و بازیابی اون |
| فیلتر کلمات | سقف بالاتر برای تعداد کلمات |
| رسانه موقت | رسانه‌هایی که خودکار حذف می‌شن |
| ضدخیانت مدیران | محافظت در برابر خیانت مدیرها |
| هوش مصنوعی پیشرفته | بعضی قابلیت‌های پیشرفته |
| چت‌بات | سهمیه بیشتر برای چت‌بات هوشمند |

### قیمت‌ها

قیمت پیش‌فرض پلن‌ها:

| مدت اشتراک | قیمت |
|:---|---:|
| یک ماه | ۱۵۰ Telegram Stars |
| سه ماه | ۴۰۰ Telegram Stars |
| دوازده ماه | ۱۴۰۰ Telegram Stars |

برای خرید، پیوی ربات رو باز کن و **«خرید پریمیوم»** رو بزن. قیمت نهایی و پلن‌های قابل خرید رو همون‌جا چک کن، چون ممکنه قیمت‌ها عوض بشن.

---

## Premium رایگان چطوری بگیرم؟

با دعوت دوستات:

۱. وارد پیوی ربات شو.

۲. دستور `/ref` رو بفرست.

۳. لینک دعوت اختصاصیت رو برای دوستت بفرست.

۴. دوستت باید از همون لینک وارد ربات بشه و بعدش ارجین رو به یه گروه اضافه کنه تا شرط پاداش کامل بشه.

پاداش پیش‌فرض برای دعوت‌کننده **۲ روز Premium** هست. فقط بازکردن لینک یا Start کردن ربات برای کامل‌شدن شرط کافی نیست.
