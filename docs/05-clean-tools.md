# ابزارهای مدیریتی

### ابزارهای مدیریتی

- پاک‌سازی اخطارها و شمارنده‌های دعوت
- دیدن فهرست بن‌شده‌ها و ساکت‌شده‌ها
- آزادکردن اعضا از بن یا سکوت
- پاک‌سازی ربات‌ها و حساب‌های حذف‌شده‌ای که ارجین می‌شناسه
- همگام‌سازی فهرست مدیرها
- بازنشانی تنظیمات گروه (فقط مالک)
- نسخه پشتیبان و بازیابی (برای کاربران **Premium**)

> **محدودیت تلگرام:** ارجین نمی‌تونه فهرست کامل همه اعضای گروه رو از تلگرام بگیره. بعضی ابزارهای پاک‌سازی و تگ‌کردن فقط روی اعضایی کار می‌کنن که ربات قبلاً دیده و ثبتشون کرده.
