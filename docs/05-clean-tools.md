# 🧹 موتورهای پاکسازی گروهی و نظافت سریع چت

**دسترسی گرافیکی:** `پنل` ← «🚀 تنظیمات پیشرفته» ← «🧹 پاکسازی گروه» (۵۰/۱۰۰ پیام اخیر، پاکسازی ربات‌ها، دلیتی‌ها، لیست سکوت و بن)

---

## 📑 جدول کامل دستورات پاکسازی

| دستور | معادل / دستور اسلش | عملکرد |
|---|---|---|
| `حذف` | `دلیت` \| `پاک کن` \| `/del` \| `/delete` *(با ریپلای)* | حذف فوری یک پیام مشخص |
| `پاکسازی [تعداد]` | `حذف [تعداد]` — بازهٔ مجاز از ۱ تا ۲۰۰ | حذف سریع پیام‌های متوالی اخیر گروه |
| `پاکسازی ربات ها` | `/cleanbots` | شناسایی و اخراج یکجای تمامی ربات‌های متفرقهٔ چت |
| `پاکسازی دیلیتی ها` | `/cleandeleted` | پاکسازی کامل اکانت‌های دیلیت‌شدهٔ تلگرام از گروه |
| `پاکسازی لیست سکوت` | `/unmuteall` | رفع سکوت همگانی از تمام کاربران سایلنت‌شده |
| `پاکسازی لیست بن` | `/unbanall` | رفع مسدودی از کلیهٔ کاربران اخراج‌شدهٔ تاریخچهٔ گروه |
| `پاکسازی لیست فیلتر` | — | حذف تمام واژگان موجود در لیست سیاهِ فیلتر کلمات گروه |
| `پاکسازی پاسخ ها` | `پاکسازی پاسخ‌ها` | حذف یکجای کلیهٔ پاسخ‌های خودکار تعریف‌شده |
| `پاکسازی اخطارها` | — | صفر کردن سوابق اخطار همهٔ اعضا *(به [۰۴ - مدیریت اعضا](./04-moderation.md) نیز مراجعه کنید)* |
| `پاکسازی ادها` | — | ریست کامل آمار اد گروه *(به [۰۸ - اد اجباری](./08-force-add-fsub-captcha.md) نیز مراجعه کنید)* |

### 🔢 مثال‌های کاربردی

```text
پاکسازی 50
```
▶️ حذف ۵۰ پیام اخیر گروه

```text
پاکسازی 100
```
▶️ حذف ۱۰۰ پیام اخیر گروه
