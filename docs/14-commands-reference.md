## ⚙️ دستورات پایه و نصب

| دستور | معادل | عملکرد |
|---|---|---|
| `نصب` | `فعالسازی` \| `/install` \| `/start` \| `setup` | ثبت اولیهٔ گروه در ربات |
| `پنل` | `تنظیمات` \| `/panel` | باز کردن کنترل‌پنل گرافیکی |
| `ریلود` | `همگام سازی` \| `/reload` | به‌روزرسانی لیست ادمین‌ها |
| `تنظیم زبان` | — | انتخاب زبان فارسی یا انگلیسی |
| `پینگ` | — | تست سرعت و آنلاین‌بودن سرور |
| `بازنشانی تنظیمات` | — | بازگشت کامل به تنظیمات کارخانه |

## 🔒 قفل‌ها (خلاصه)

فهرست کامل بیش از ۳۰ قفل در سند [۰۲ - قفل‌ها و محدودیت‌ها](./02-locks.md) آمده است. الگوی کلی دستورات:

```text
قفل [مورد نظر]        ⇠ فعال‌سازی قفل
بازکردن [مورد نظر]    ⇠ غیرفعال‌سازی قفل
وضعیت قفل ها (یا /locks) ⇠ مشاهدهٔ وضعیت کلی
```

## ⚠️ اخطار / سکوت / بن (خلاصه)

| دستور | عملکرد |
|---|---|
| `اخطار` / `حذف اخطار` / `سقف اخطار [عدد]` | مدیریت سیستم اخطار |
| `سکوت` / `سکوت [مدت]` / `رفع سکوت` | مدیریت سکوت موقت |
| `بن` / `رفع بن` | اخراج و رفع مسدودیت |
| `پین` / `حذف پین` | سنجاق و حذف سنجاق پیام |

جزئیات کامل → [۰۴ - مدیریت اعضا](./04-moderation.md)

## 🧹 پاکسازی (خلاصه)

| دستور | عملکرد |
|---|---|
| `حذف` | حذف یک پیام ریپلای‌شده |
| `پاکسازی [تعداد]` | حذف دسته‌جمعی پیام‌های اخیر |
| `پاکسازی ربات ها` / `پاکسازی دیلیتی ها` | پاکسازی ربات‌ها و اکانت‌های حذف‌شده |
| `پاکسازی لیست سکوت` / `پاکسازی لیست بن` | آزادسازی همگانی |

جزئیات کامل → [۰۵ - ابزار پاکسازی](./05-clean-tools.md)
