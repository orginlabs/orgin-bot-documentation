# فهرست دستورها

## فهرست دستورها

دستورها رو توی گروه بفرست و هرجا لازم بود روی پیام عضو ریپلای کن. بعضی دستورها فقط برای مدیرها یا کاربران Premium کار می‌کنن.

<details>
<summary><b>دستورهای اصلی</b></summary>

<br>

| دستور | کاربرد |
|:---|:---|
| `/start` | شروع کار با ربات و نمایش منو |
| `/help` | نمایش راهنما |
| `/lang` | انتخاب زبان، در صورت دسترسی |
| `/ref` | دریافت لینک دعوت برای پاداش Premium |
| `پنل` یا `panel` | نمایش دکمه ورود به پنل گروه |
| `نصب` یا `install` | راهنمای فعال‌سازی ربات در گروه |
| `نسخه` یا `version` | نمایش نسخه و تغییرات |

</details>

<details>
<summary><b>مدیریت اعضا</b></summary>

<br>

| دستور | کاربرد |
|:---|:---|
| `بن` / `ban` | بن‌کردن عضو |
| `رفع بن` / `unban` | برداشتن بن |
| `کیل` / `kick` | اخراج عضو |
| `سکوت` / `mute` | محدودکردن ارسال پیام؛ بدون زمان، معمولاً ۳۰ دقیقه |
| `سکوت 10m` / `mute 10m` | سکوت به مدت مشخص |
| `رفع سکوت` / `unmute` | برداشتن سکوت |
| `اخطار` / `warn` | ثبت اخطار |
| `حذف اخطار` / `unwarn` | حذف اخطار |
| `اخطارها` / `warns` | مشاهده اخطارها |
| `پاکسازی اخطارها` / `warnreset` | پاک‌کردن اخطارها |
| `تنظیم اخطار 3` / `setwarn 3` | تعیین سقف اخطار |
| `اقدام اخطار بن` / `warnact ban` | انتخاب اقدام بعد از رسیدن به سقف |
| `ارتقا مدیر` / `promote` | ارتقای نقش مدیریتی، در صورت مجازبودن |
| `عزل مدیر` / `demote` | برداشتن نقش مدیریتی، در صورت مجازبودن |

مدت‌زمان‌ها رو با قالب‌هایی مثل `30s`، `10m`، `2h` و `1d` بنویس.

</details>

<details>
<summary><b>پیام‌ها و قفل‌ها</b></summary>

<br>

| دستور | کاربرد |
|:---|:---|
| `پین` / `pin` | پین‌کردن پیام ریپلای‌شده |
| `حذف پین` / `unpin` | برداشتن پین |
| `حذف` / `del` | حذف پیام ریپلای‌شده |
| `پاکسازی 50` / `purge 50` | پاک‌سازی تعداد مشخصی پیام |
| `قفل لینک` / `lock link` | قفل‌کردن لینک‌ها |
| `بازکردن لینک` / `unlock link` | بازکردن قفل لینک |
| `قفل چت` / `lock chat` | بستن ارسال پیام در گروه |
| `بازکردن چت` / `unlock chat` | بازکردن ارسال پیام |
| `وضعیت قفل ها` / `locks` | نمایش وضعیت قفل‌ها |
| `ضد اسپم روشن` / `antispam on` | روشن‌کردن ضداسپم |
| `ضد فلود روشن` / `flood on` | روشن‌کردن ضدفلود |
| `کاپچا روشن` / `captcha on` | روشن‌کردن کپچا |
| `حالت شب روشن` / `night on` | روشن‌کردن حالت شب |

برای خاموش‌کردن بیشتر گزینه‌های امنیتی، به‌جای «روشن» بنویس «خاموش»، یا از پنل تغییرش بده.

</details>

<details>
<summary><b>محتوا و قوانین</b></summary>

<br>

| دستور | کاربرد |
|:---|:---|
| `قوانین` / `rules` | نمایش قوانین گروه |
| `تنظیم قوانین` / `setrules` | ثبت قوانین؛ متن رو بعد از دستور بنویس یا روی متن ریپلای کن |
| `حذف قوانین` / `delrules` | حذف قوانین |
| `تنظیم خوشامد` / `setwelcome` | تنظیم پیام خوشامد |
| `تنظیم خروج` / `setgoodbye` | تنظیم پیام خداحافظی، در صورت مجازبودن |
| `فیلتر کلمه1, کلمه2` / `filter word1, word2` | افزودن کلمات به فیلتر |
| `حذف فیلتر کلمه1` / `unfilter word1` | حذف یک کلمه از فیلتر |
| `لیست فیلتر` / `filters` | نمایش کلمات فیلترشده |
| `پاسخ سلام به درود!` / `reply hi to Hello!` | ساخت پاسخ خودکار |
| `حذف پاسخ سلام` / `unreply hi` | حذف پاسخ خودکار |
| `لیست پاسخ` / `replies` | نمایش پاسخ‌های خودکار |

</details>

<details>
<summary><b>امنیت و رشد گروه</b></summary>

<br>

| دستور | کاربرد |
|:---|:---|
| `ضد تبچی روشن` / `antitabchi on` | روشن‌کردن ضدتبچی |
| `قفل ربات` / `lock bots` | کنترل ورود ربات‌ها |
| `تأیید عضویت روشن` | روشن‌کردن بررسی عضویت، در صورت پشتیبانی |
| `ضد خیانت روشن` / `antibetray on` | قابلیت Premium؛ محافظت مربوط به مدیرها |
| `اد اجباری 3` / `fadd 3` | تعیین تعداد دعوت اجباری |
| `اد اجباری خاموش` / `fadd off` | خاموش‌کردن دعوت اجباری |
| `وضعیت اد من` / `myadds` | مشاهده وضعیت دعوت‌های خودت |
| `پاکسازی ادها` / `resetadds` | بازنشانی شمارنده دعوت، برای مدیر مجاز |
| `تنظیم کانال @channel` / `fsub @channel` | تنظیم کانال عضویت اجباری، در صورت دسترسی |
| `حذف کانال` / `fsubdel` | حذف کانال از تنظیمات عضویت اجباری |
| `گزارش` / `report` | گزارش پیام ریپلای‌شده به مدیرها |
| `لینک` / `link` | باز‌کردن منوی ساخت و دریافت لینک دعوت |

</details>

<details>
<summary><b>ابزارها و Premium</b></summary>

<br>

| دستور | کاربرد |

| `پاکسازی دیلیتی ها` / `cleandeleted` | پاک‌سازی حساب‌های حذف‌شده شناسایی‌شده |
| `لیست سکوت` / `mutelist` | فهرست ساکت‌شده‌ها |
| `لیست بن` / `banlist` | فهرست بن‌شده‌ها |
| `ریلود` / `reload` | همگام‌سازی فهرست مدیرها |
| `بازنشانی تنظیمات` / `reset` | بازنشانی تنظیمات؛ فقط مالک مجاز |
| `تیکت مشکل من` / `ticket my problem` | ثبت تیکت پشتیبانی |
| `لیست تیکت` / `tickets` | نمایش تیکت‌ها برای کاربر مجاز |
| `پاسخ تیکت 1 متن` / `ticketreply 1 text` | پاسخ به تیکت مشخص |
| `بستن تیکت 1` / `closeticket 1` | بستن تیکت مشخص |
| `پشتیبان` / `backup` | درخواست نسخه پشتیبان برای گروه واجد شرایط |
| `بازیابی` / `restore` | بازیابی با ریپلای روی فایل پشتیبان |
| `تنظیم رسانه موقت 30` / `tempmedia 30` | تنظیم رسانه موقت، در صورت فعال‌بودن Premium |

</details>

> **توجه:** این دستورها بسته به نقش کاربر، زبان گروه، دسترسی‌های تلگرام و فعال‌بودن قابلیت ممکنه محدود باشن. اگه دستوری اجرا نشد، اول `/help` رو ببین و مطمئن شو ارجین دسترسی لازم رو داره.
